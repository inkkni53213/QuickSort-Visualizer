# 快速排序双指针交互动画演示 (QuickSort Visualizer)

这是一个基于 HTML/CSS/JS 的纯前端交互项目，用于直观地演示快速排序（双指针法）的内部逻辑。

## 💡 项目背景
制作该项目的灵感来源《计算机科学技术导论》这门课的一个实验：人体计算机排序，在询问两个AI还是看不懂、从B站上找了两个可视化模型还觉得不够直观后，为了帮助自己与组员更好地理解，我借助大语言模型辅助生成了这个可视化网页。

## ✨ 核心功能
- 支持自定义生成 1~100 个随机排序元素。
- 实时显示左指针（L）、右指针（R）及基准点（Pivot）。
- 记录并显示当前的比较步数、移动状态。
- 动画展示元素交换过程。

## 🛠️ 技术栈
- 原生 JavaScript (无需安装任何依赖，双击即可在浏览器运行)
- HTML5 + CSS3

## 🎮 如何体验？
1. 克隆本仓库：`git clone https://github.com/inkkni53213/QuickSort-Visualizer`
2. 双击打开 `outputs/index.html` 即可。
